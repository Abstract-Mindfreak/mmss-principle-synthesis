# Skill Quick Sampler

<p align="center"><img src="skill-quick-sampler-icon.svg" width="128" height="128" alt="Skill Quick Sampler"></p>


Quick sampling of skill instructions from a remote or local directory (GitHub tree URL, raw listing, or local path). Select N instructions, emit one short usage example per instruction, and allow easy switch of the source URL or path. Use for rapid overview, example generation, or lightweight inventory of a skill collection without loading full SKILL.md bodies. Triggers include quick sample, sample skills, one example per skill, list 30 skills with examples, browse skill catalogue, change skills source.

## Skill file

[`SKILL.md`](../../../skills/skill-quick-sampler/SKILL.md) contains the complete instructions.
