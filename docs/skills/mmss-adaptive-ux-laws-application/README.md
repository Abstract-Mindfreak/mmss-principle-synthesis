# MMSS Adaptive UX Laws Application

<p align="center"><img src="mmss-adaptive-ux-laws-application-icon.svg" width="128" height="128" alt="Mmss Adaptive Ux Laws Application"></p>


Adaptive sequential application of Laws of UX (and hybrids) for multi-pass UI/UX review and improvement proposals. Collects element data, identifies applicable laws and hybrids, produces a map of change proposals, and defines goals plus success criteria. Multiple operating modes support both deep analysis and rapid capture of small details. Finding and recording shortcomings is the primary goal; implementing fixes is out of scope.
