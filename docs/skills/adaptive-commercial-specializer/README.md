# Adaptive Commercial SPecializer

<p align="center"><img src="adaptive-commercial-specializer-icon.svg" width="128" height="128" alt="Adaptive Commercial Specializer"></p>


Generates practically usable commercial specializations from available material (existing skills, session findings, tools, external signals, user constraints). Prioritizes movement toward useful action while keeping exploration available; decides autonomously when to research, crystallize, execute, or hold. Commercial orientation is mandatory; industry, business model, and form remain open variables. Treats missing data and mismatch with familiar models as material, not automatic rejection criteria. Does not fabricate demand, income, permissions, or external execution.
