# Adaptive Open Skill Synthesizer

<p align="center"><img src="adaptive-open-skill-synthesizer-icon.svg" width="128" height="128" alt="Adaptive Open Skill Synthesizer"></p>


Adaptive discovery and materialization of new skills under open S and P variables, without fixed catalogues of entities, roles, or algorithms. Use when the agent must invent, reshape, or combine skills from productive findings, auto-select search strategies, generate new modes, or extend MMSS stacks by open combinatory synthesis that preserves parent contracts and boundary identity. Triggers include adaptive skill creation, open skill synthesis, invent new skill from findings, generate skill mode, transform skill, combinator, exploratory skill materialization.
