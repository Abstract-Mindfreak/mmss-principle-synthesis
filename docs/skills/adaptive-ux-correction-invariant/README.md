# Adaptive UX Correction Invariant

<p align="center"><img src="adaptive-ux-correction-invariant-icon.svg" width="128" height="128" alt="Adaptive Ux Correction Invariant"></p>


Практическая диагностика и минимальные UX-исправления на основе деформационно-устойчивых инвариантов внимания, плотности, режимов, однонаправленного потока, разделения состояний и безопасных мутаций. Компактный скилл; полные формулы, envelope и repair-правила наследуются от предков (adaptive-universal-invariant-synthesizer, mmss-principle-synthesis, mmss-skill-boundary-combinator, data-to-skill, session-to-skill). Используй для исправления интерфейсов, проверки соблюдения UX best-practice mechanisms и выдачи ранжированных минимальных правок.
