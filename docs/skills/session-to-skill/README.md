# Session To Skill

<p align="center"><img src="session-to-skill-icon.svg" width="128" height="128" alt="Session To Skill"></p>


Transform a recorded agent session (or its process log) into a new minimal-sufficient skill by extracting only the deformation-stable constructive patterns, applying boundary-identity at every representation crossing, isolating the robust kernel of the process, and emitting a provenance-preserving skill. Use when the agent must turn a productive session history, process log, or multi-step extraction sequence into a reusable skill without copying domain content as authority.
