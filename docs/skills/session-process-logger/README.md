# Session Process Logger

<p align="center"><img src="session-process-logger-icon.svg" width="128" height="128" alt="Session Process Logger"></p>


Creates compact, traceable retrospective history logs of an agent session from available messages, materials, skill references, tool calls, results, and artifact changes. Distinguishes observed traces from claimed actions and retrospective interpretations. Supports full-session, partial/fragment, and notation-proposal modes. Does not reconstruct hidden reasoning, invent events, or execute past actions.
