# Data To Skill

Transform arbitrary inspectable data, specifications, corpora or prior artifacts into provenance-preserving, minimal-sufficient skills under open S and P variables. Applies selective principle extraction, boundary-identity at every representation crossing, layered projection with explicit information-loss accounting, robust-kernel isolation, and a variational minimality criterion. Use when the agent must turn raw or structured material into a reusable skill without closed entity catalogues or fabricated mechanisms. Triggers include data to skill, turn this into a skill, synthesize skill from source, materialize skill from principles, provenance-preserving skill builder.
