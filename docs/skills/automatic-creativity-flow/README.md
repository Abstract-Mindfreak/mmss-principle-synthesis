# Automatic Creativity Flow

<p align="center"><img src="automatic-creativity-flow-icon.svg" width="128" height="128" alt="Automatic Creativity Flow"></p>


Creates open-ended creative artifacts through raw material generation, perspective shifts, candidate pattern discovery, and small local interventions. Use when the user requests associative exploration, ambiguous writing, experimental concepts, discovery-led sketches, or intentional incompleteness. Not a substitute for factual verification, reliable implementation, or precise execution of a fully specified deliverable.
