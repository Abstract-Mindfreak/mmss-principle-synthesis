# MMSS Adaptive SP Combinator

<p align="center"><img src="mmss-adaptive-sp-combinator-icon.svg" width="128" height="128" alt="Mmss Adaptive Sp Combinator"></p>


Adaptive discovery, transformation, and combination of skills, systems, properties, and of the combination methods themselves, under open S and P variables. Use when the agent must find, reshape, or invent combinations without fixed entity lists, role catalogues, or algorithm menus; when auto-select should choose or generate the search approach; when new modes must be born from productive findings; or when mmss-principle-synthesis needs an open combinatory layer that preserves parent contracts. Triggers include: adaptive combination, open S P, discover approaches, generate new mode, transform combination method, auto-select search strategy, vector-scheme reactivation, exploratory skill synthesis.
