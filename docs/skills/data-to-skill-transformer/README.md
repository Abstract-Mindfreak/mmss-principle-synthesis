# Data To Skill Transformer

<p align="center"><img src="data-to-skill-transformer-icon.svg" width="128" height="128" alt="Data To Skill Transformer"></p>


Transform arbitrary data, artifacts or descriptions into a new minimal-sufficient skill by applying a universal constructive method of constrained state dynamics, projection maps, discrete protective invariants, variational guidance and boundary-identity preservation. Use when the agent must turn source material into a reusable skill, materialize a skill from findings, or construct a skill under open variables while preserving provenance and avoiding fabrication.
