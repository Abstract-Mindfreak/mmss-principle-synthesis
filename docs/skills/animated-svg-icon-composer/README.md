# Animated SVG Icon Composer

<p align="center"><img src="animated-svg-icon-composer-icon.svg" width="128" height="128" alt="Animated Svg Icon Composer"></p>


Compose a self-contained animated SVG icon for any object, concept, tool, service, idea, or skill — not necessarily MMSS. Works from a semantic skeleton of the target (what it is, what acts, what changes, what it emits) or from a property, relation, or state when no process exists. Renders that reading as a readable motion metaphor. Accepts open input parameters (topic, purpose, palette, style, shape, background, size, intensity, references). Emits one standalone SVG, a brief idea description, an optional element→meaning map, a README embedding example, and an honest account of what was verified versus proposed. Primary target environment is a GitHub README image; the skill is honest about what works there and what is uncertain. CSS, SMIL, or both are acceptable depending on the motion. No external resources, no JavaScript, no fixed palette, no fixed archetype library, no RAG/CAG infrastructure.
