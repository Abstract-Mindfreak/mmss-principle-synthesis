# Adaptive UX Orchestrator

<p align="center"><img src="adaptive-ux-orchestrator-icon.svg" width="128" height="128" alt="Adaptive Ux Orchestrator"></p>


Тонкий оркестратор двух UX-скиллов: mmss-adaptive-ux-laws-application (каталог Laws of UX + гибриды, поиск недостатков) и adaptive-ux-correction-invariant (жёсткие операционные инварианты внимания/плотности/режимов/потока/безопасных мутаций). Координирует последовательность, разрешает конфликты (инварианты имеют приоритет на жёстких ограничениях), поддерживает несколько режимов работы. Не дублирует логику детей; ссылается на них и на общих предков.
